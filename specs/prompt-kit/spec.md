# Prompt Kit (prompt-kit)

근거: SRS v1.0 FR-PREM-03 · 결정 2026-10-27 (핵심 기능 = Prompt Kit) · 프로토타입 v4 (키트 화면)

상태: 뼈대. 시나리오는 이 기능을 만들 때 채워요.

## Requirements

### Requirement: FR-PREM-03 Prompt Kit 만들기
시스템은 연결 결과, 공고 정리, 사업부 맥락을 묶어 사용자가 자기 AI에 붙여 넣을 Prompt Kit(`PromptKit`)을 만들고, 복사와 내려받기(마크다운, PDF)를 할 수 있게 해야 한다(SHALL). 프리미엄 기능이다.
