# 공고 (posting)

근거: SRS v1.0 FR-POST-01 · 결정 2026-11-10 (공고 PDF 업로드), 2026-11-09 (공고는 외부에서 가져와 서비스 안에서 가공), NFR-EXT-02 (채용 플랫폼 크롤링 금지) · 프로토타입 v4 (공고 달력, 공고 분석)

상태: 뼈대. 시나리오는 이 기능을 만들 때 채워요.

## Requirements

### Requirement: FR-POST-01 공고 정리
시스템은 사용자가 올린 채용공고(`JobPosting`, PDF)를 읽어 주요 업무, 자격 요건, 우대 사항, 요구 역량, 마감일을 정리(`PostingAnalysis`)하고, 공고에 적힌 것과 AI가 추론한 것을 구분해 보여줘야 한다(SHALL). 쿼터가 적용된다.

### Requirement: POST-02 공고 달력
시스템은 저장한 공고를 마감일 기준 달력과 상태(관심, 지원, 면접)로 보여줘야 한다(SHALL).

> OPEN: 공고 자동 수집 경로 (개인 이용 가능한 민간 공고 API 없음, 2026-11-10).
