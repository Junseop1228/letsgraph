# 경험 (portfolio)

근거: SRS v1.0 FR-PREM-01 · 결정 2026-10-27 (형식 없는 포트폴리오), 2026-11-09 (pdf, docx, pptx, GitHub 링크; hwp 제외; 자기소개서 포함; 경험 카드로 변환), 2026-11-10 (업로드 파일 처리 규칙: 본인만, 원본 PDF 삭제)

상태: 뼈대. 시나리오는 이 기능을 만들 때 채워요.

## Requirements

### Requirement: FR-PREM-01 경험 카드 만들기
시스템은 사용자가 올린 포트폴리오와 자기소개서에서 경험(`Experience`)을 추출해 경험 카드로 보여주고, 사용자가 고치고 지울 수 있게 해야 한다(SHALL). 파일을 AI로 보낸다는 사실을 올리기 전에 알린다. 쿼터가 적용된다.

### Requirement: PORT-02 경험 대화
시스템은 대화로 경험을 보충하고, 대화 끝에 경험 카드 초안을 요약해 저장할지 묻게 해야 한다(SHALL).
